# Security review, round 01 — pre-publish

## Verdict

Clean. Nothing above nit. Every URL parameter and every localStorage value is either enum-validated, numerically clamped, or routed through `escapeHtml` before it reaches a DOM sink, and the fetch surface is limited to hardcoded same-origin paths. Ship as-is.

## Findings

None at blocker or should-fix.

### Nits (defense in depth only)

- **n1** — No CSP meta tag on `index.html`. GitHub Pages will not set response headers, but a `<meta http-equiv="Content-Security-Policy">` on the shared origin would contain any future XSS regression before it could reach a sibling site under `maninae.github.io`. Suggested policy that matches what this page actually uses: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src https://fonts.gstatic.com; img-src 'self' data:; connect-src 'self'; worker-src 'self'; object-src 'none'; frame-ancestors 'none'; base-uri 'self'; form-action 'none'`. Zero inline scripts today, so `script-src 'self'` costs nothing.
- **n2** — Google Fonts CSS at `fonts.googleapis.com/css2?family=Barlow:...` (`index.html:24`) loads without SRI. SRI is not possible for a dynamic CSS URL that Google may resize per-viewport; a fonts.googleapis.com compromise would leak visitor IPs and could serve arbitrary CSS. Standard trade-off, matches every sibling public site under maninae; leaving this alone.
